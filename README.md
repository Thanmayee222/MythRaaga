# 🎮 MythRaaga - AI-Generated Folktales 🎭

MythRaaga is an AI-powered folktale generation platform that creates engaging stories in multiple languages.  
It uses **Gemini API** to generate unique folktales and presents them in a user-friendly format.

---

## ✨ Features  
✔️ AI-generated folktales using **Gemini API**  
✔️ Supports **3 languages** for diverse storytelling  
✔️ Engaging and interactive user experience  
✔️ Future-ready architecture for expansion  

---

## 🔧 Setup & Installation  

### **1⃣ Clone the Repository**  
```bash
git clone https://github.com/Thanmayee222/MythRaaga.git
cd MythRaaga
```

### **2⃣ Create a Virtual Environment (Optional but Recommended)**
```bash
python -m venv venv
source venv/bin/activate  # For macOS/Linux
venv\Scripts\activate  # For Windows
```

### **3⃣ Install Dependencies**
```bash
pip install -r requirements.txt
```

### **4⃣ Add Your API Key**
- Create a file named **`apikey.txt`** inside the project folder.
- Add your Gemini API key inside the file (this file is ignored by Git).

### **5⃣ Run the Application**
```bash
python app.py  # Replace with your main script
```
